# Custom Collision Box

A simple Minecraft datapack library that allows creating custom collision/interaction boxes with basic management.

## Features

* **Creation**: Create a collision box or a interaction box.
* **Management**: Update and remove boxes.

## Dependencies

Some features of the datapack depend on Bookshelf Modules.

### Data Packs

* (optional) [Bookshelf Link](https://modrinth.com/datapack/bookshelf-link)
